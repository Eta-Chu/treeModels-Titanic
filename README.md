# treeModels-Titanic

Implementations and experiments for the [Spaceship Titanic competition on Kaggle](https://www.kaggle.com/competitions/spaceship-titanic), with a focus on understanding tree-based models from theory to practice.

The models explored in this project include:

- Logistic Regression
- Multilayer Perceptron (MLP)
- Decision Trees (CART)
- Random Forest
- AdaBoost
- Gradient Boosting Decision Trees (GBDT)
- XGBoost

For each tree-based algorithm, the project includes a simple implementation from scratch, experiments and evaluation, and detailed study notes explaining the underlying ideas and mathematical derivations.

**Leaderboard ranking:** 559 out of 2,043 as of November 13, 2026.
